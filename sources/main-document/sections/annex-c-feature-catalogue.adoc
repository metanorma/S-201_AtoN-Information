== Feature catalogue

This annex renders the S-201 Feature Catalogue directly from its
S-100FC instance document (`schema/S-201_Feature_Catalogue.xml`) against
the published S-100 Feature Catalogue schema (`schema/S100FC.xsd`). The
content is not maintained in this document: the catalogue file is the
source of record, and this annex is its rendering.
